# Murex

A Murex-style capital-markets practice platform for learning trading, market data, pricing, P&L, risk, operations, SQL/PLSQL, and Business Analysis workflows.

## Modules
- Dashboard
- Trade Capture
- Market Data
- Products & Reference Data
- Pricing
- P&L
- Risk
- Confirmation & Settlement
- BA Issue Lab

## UI
Enterprise purple / deep-violet theme with neutral grey, blue-grey and off-white data grids.

> This is an original educational practice platform inspired by capital-markets workflows. It is not the proprietary Murex MX.3 software.
